# Changelog

## Standalone project documentation

- Document installation, data generation, MDP fitting, policy simulation and outputs as one standalone Python project.
- Describe the figure's groups, pooled standard deviations and quarterly timing.
- Retain explicit model assumptions and discrepancies with the publication.
- Documentation, descriptive metadata and help-text updates do not change numerical calculations.

## Analysis features

- Synthetic longitudinal patient-data generator with a bundled reference dataset.
- Eight-state MDP with value iteration and three-policy trajectory comparisons.
- Frail and Fit plots with three policies per panel and a default 0–60-month axis.
- CSV/NPZ results, run metadata, pinned dependencies and 14 regression checks.
